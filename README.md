# Circle Chase

A small maze game made for a UX design class exercise. Eat every dot and keep away from the squares. After a power dot the squares turn blue and can be caught, and a timer in the top wall shows how long that lasts.

Play: https://anderson00402.github.io/circle-chase/

Controls: arrow keys or WASD to move, P to pause. On a phone, swipe on the board.
